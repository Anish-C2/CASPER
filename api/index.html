CASPER DATA API

Competition Archive & Historical Record System
Raw CSN. Parsed data. Filtered data. One source.

Public data interface — v1

The canonical archive remains CSN. The API client exposes raw CSN plus parsed competitions, matches, players, teams, awards and rankings, with sport/season/team/player/stage filters.

Static-host compatible: no database or server runtime is required.

Raw CSN

CASPER_API.rawCSN('futsal','2026A')

Returns the original CSN text exactly as stored in the archive.

Filtered CSN

CASPER_API.filterCSN({sport:'futsal',season:'2026A',competition:'Finale'})

Returns matching CSN tournament blocks while preserving the source notation.

All data

CASPER_API.all({sport:'football',season:'2026A'})

Returns competitions, matches, teams, players, awards and rankings together.

Individual resources

matches / players / teams / competitions / awards / rankings

Every resource accepts the same filter object.

Filters

sport · season · competition · competitionId · player · team · stage
